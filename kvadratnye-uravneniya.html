Решение квадратных уравнений

Корни уравнения ax² + bx + c = 0 через дискриминант — с подробным решением.

Формулы

Дискриминант D = b² − 4ac. Если D > 0 — два корня x = (−b ± √D) ÷ 2a; если D = 0 — один корень x = −b ÷ 2a; если D < 0 — действительных корней нет (есть комплексные).
