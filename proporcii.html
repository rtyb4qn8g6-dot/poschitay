Найдите неизвестное в пропорции a : b = c : x — правило креста за секунду.

Правило креста

В пропорции a : b = c : x произведение крайних членов равно произведению средних: a · x = b · c, значит x = b · c ÷ a.

Пример: если 3 яйца нужны на 150 г муки, то на 5 яиц нужно x = 150 × 5 ÷ 3 = 250 г муки.
