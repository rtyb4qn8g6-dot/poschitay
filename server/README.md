# ИИ-чат «Посчитай»

Node.js 22 или новее. Для локальной проверки из корня репозитория:

```sh
POSCHITAY_PREVIEW=1 node server/index.mjs
```

Откройте `http://127.0.0.1:8787/ai-chat`. Для настоящих ответов настройте `OPENAI_API_KEY` средствами хранения секретов среды запуска. Не добавляйте ключ в HTML, JavaScript сайта или Git. `OPENAI_MODEL` можно переопределить. По умолчанию используется `gpt-4.1-mini`.

GitHub Pages обслуживает HTML и клиентские ассеты. Запустите Node-сервер на отдельном HTTPS-хосте. Проксируйте `/api/chat` с основного домена либо задайте абсолютный API-адрес в meta-теге `ai-chat-endpoint` страницы. При внешнем прокси задайте `HOST`, `PORT` и точный origin страницы в `POSCHITAY_ORIGIN`. Для публичного запуска проверьте лимит расходов проекта, HTTPS и ограничения запросов на прокси. Встроенные ограничения действуют на процесс сервера и учитывают адрес непосредственного подключения. За прокси ограничивайте посетителей также на его стороне.

Сервер не пишет сообщения в файлы и отправляет их в OpenAI Responses API с `store: false`. Диалог передаётся до 12 сообщений за запрос. Модель запрашивает арифметические операции у ограниченного вычислителя, а сервер выдаёт ссылки только на известные страницы каталога.
