# Посчитай

Статический сайт онлайн-калькуляторов для пользователей в России: https://poschitay24.ru/.
Главная очередь развития и состояние работ — docs/razvitie.md.

## Работа команды

Пользователь поручил вести разработку через агентов. Для задач, которые выигрывают от параллельной работы, ведущий агент распределяет конкретный выпуск:

- Разработка: интерфейс, чистые функции расчёта, понятные допущения.
- Каталог и SEO: ссылки, поиск, метаданные, sitemap и связанные инструменты.
- Проверка: независимые численные примеры, граничные случаи и регрессии.
- Ведущий: согласование областей файлов, проверка изменений, визуальная проверка и публикация.

У каждой задачи должен быть конечный проверяемый результат. Не имитировать фоновую работу после окончания сессии; расписания создаются отдельным механизмом при соответствующем поручении.

## Изменения

- Сначала читать существующие файлы и сохранять рабочие калькуляторы, фирменное оформление, поиск и мобильный интерфейс.
- Агентам выделять непересекающиеся файлы. Запись в основную ветку координирует ведущий; не публиковать конкурирующие версии одного файла.
- Проверять свежесть исходной версии перед публикацией; связанные изменения страницы, ассетов и каталога по возможности выпускать одним коммитом.
- Для новой страницы обновлять каталог, поиск в assets/app.js, sitemap.xml и кэш sw.js. Счётчик каталога должен соответствовать фактически добавленным калькуляторам.
- Формулы держать проверяемыми; тестировать значимые границы и округление, а не копировать реализацию в тесты.
- Не вводить новые зависимости, сервер, аккаунты и платные интеграции без задачи, которой они необходимы.

## Достоверность и интерфейс

- Раскрывать допущения, единицы измерения, источники изменяемых норм и формулы.
- Демонстрационные расходы материалов явно помечать; позволять заменить их значениями производителя.
- Ввод проверять на конечность, допустимый диапазон и нулевые делители. Показывать понятные сообщения об ошибке.
- Проверять узкий экран, клавиатуру и предпочтение уменьшенного движения.
- Не отправлять значения личных полей в события аналитики. Передача расчёта по ссылке должна быть явным действием пользователя.
- SEO строить вокруг полезной задачи, естественного текста и проверенных примеров; не создавать дубли ради количества и не обещать места в поиске.
- Не включать рекламу, финансовые операции или рассылки без соответствующего поручения пользователя.
